# Prompt Chaining for Summarization

## 1. Objective

The objective of this project is to demonstrate **Prompt Chaining**, where a complex summarization task is divided into multiple smaller steps.

The output generated by one prompt is passed as the input to the next prompt. This creates a structured multi-step pipeline for producing a final summary.

---

## 2. What is Prompt Chaining?

Prompt chaining is an AI technique in which multiple prompts are connected together to complete a task.

Instead of asking an AI model to perform the entire task using one prompt, the task is divided into multiple stages.

In this project, the summarization process follows three main steps:

```text
Input Text
    ↓
Step 1: Extract Key Information
    ↓
Step 2: Create Structured Summary
    ↓
Step 3: Generate Final Summary
    ↓
Final Answer
