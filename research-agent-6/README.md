# AI Research Agent

## 1. Objective

The objective of this project is to develop an AI Research Agent that searches the web for relevant information, summarizes the findings, and generates a structured research report with references.

The system combines web search with a Large Language Model (LLM) to automate the research process.

---

## 2. What is a Research Agent?

A Research Agent is an AI-powered system that can search for information from external sources, analyze the retrieved information, summarize important findings, and present the results in a structured format.

Instead of manually searching multiple websites and preparing a report, the agent performs these steps automatically.
